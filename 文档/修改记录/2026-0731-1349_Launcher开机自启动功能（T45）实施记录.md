## 二、关键决策落实

- **desktop ID 唯一出处**：`tools/desktop_entry.py` 的 `DESKTOP_ID = "zen-vocotype"`；
  运行时 `autostart.py` 同值独立定义（不跨组件 import），与安装器卸载恒删逻辑对称
- **遗留清理白名单制**：仅删 autostart 目录下 `LEGACY_DESKTOP_IDS` 列出的旧名条目，
  幂等、记日志，不触 `zen-vocotype.desktop` 本体与 applications/ 菜单条目
- **autostart 模块零三方依赖**（仅 stdlib）：dev 档 Exec 的组件根按契约库
  `component_root` 同口径由 `__file__` 推算，不 import config（避免经 pydantic
  牵连 PySide6 无关依赖），供 `--version` 探针等无 Qt 路径安全触达
- **autostart 目录解析**：`$XDG_CONFIG_HOME/autostart`（缺省 `~/.config`），
  构造期读取——测试经 monkeypatch 环境变量隔离宿主

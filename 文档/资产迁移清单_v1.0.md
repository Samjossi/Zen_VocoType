## 3. 加载与接入约束（沿用大纲 §3.5）

1. 各组件资产放各自 `assets/` 目录，随包分发
2. 加载一律走「程序自身目录」解析 helper（兼容开发环境与 PyInstaller `_MEIPASS`），🔴 禁止相对 cwd
3. 图标缺失必须记 warning，🔴 禁止静默降级为 None（旧 Launcher 在 AppImage 中静默失效为反面案例）
4. 接入时点：服务端托盘（阶段 1）、客户端托盘（阶段 2）、启动器通知（阶段 3）、.desktop（阶段 4）

## 4. 品牌图标结论

**结论：沿用迁移的旧图标占位，不阻塞主线；品牌图标新设计另行立项。**

理由：

1. 三套旧图标实物齐全、多尺寸完备，满足开发/打包两环境的显示需求
2. 品牌设计属视觉工作，与阶段 1~4 的技术主线无依赖关系
3. 加载层统一走 `assets/` + 自定位 helper，未来替换品牌图标只需替换文件，零代码改动

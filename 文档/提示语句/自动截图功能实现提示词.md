# 自动截图功能实现提示词

## 任务
为当前项目添加命令行参数控制的自动截图功能，截图保存到 `.tmp/` 目录。

## 要求
1. 使用标准库 `argparse` 解析命令行参数。
2. 支持以下参数：
   - `--auto-screenshot`：启用自动截图（布尔标志）。
   - `--screenshot-interval N`：每 N 秒截图一次（默认 1）。
   - `--screenshot-on-start`：启动时立即截一张图（布尔标志）。
3. 截图文件命名格式：`screenshot_YYYYMMDD_HHMMSS_帧序号.png`。
4. 保存路径：项目根目录下的 `.tmp/`（若不存在则自动创建）。
5. 截图方式根据当前项目渲染框架选择：
   - Pygame → `pygame.image.save(screen, path)`
   - PySide/PyQt → `widget.grab().save(path)`
   - OpenCV → `cv2.imwrite(path, frame)`
   - 其他框架 → 使用对应框架的截图/抓屏 API
6. 截图不应阻塞主循环，使用计时器或帧计数触发。

## 使用示例
```bash
# 启用自动截图，每 1 秒一张
uv run python src/main.py --auto-screenshot --screenshot-interval 1

# 启动时立即截图，之后每 5 秒一张
uv run python src/main.py --auto-screenshot --screenshot-on-start --screenshot-interval 5
```

## 输出
- 提供可直接运行的代码片段（含参数解析 + 截图逻辑）。
- 说明截图文件在 `.tmp/` 中的命名规则。
